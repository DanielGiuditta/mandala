MANDALA WINDOWS OFFICE SETUP — gateway 1.1.0 / employee 1.0.15

Download both exact files from:
https://mandala-web-tau.vercel.app/desktop-agent
MandalaGatewaySetup-1.1.0.exe
MandalaAgentSetup-1.0.15.exe
Use a Mandala admin/partner login. Windows administrator approval is required.
These are unsigned pre-launch installers; use only the audited downloads above.

IT — INTERNET-CONNECTED GATEWAY PC
1. Use a dedicated Windows 10/11 or supported Windows Server PC/VM with internet and LAN. Never use the file server or domain controller. IT must block gateway-initiated access to file servers/domain controllers at the office firewall, reserve the gateway LAN IP, and keep this PC awake. Allow employee PCs to reach only gateway HTTPS port 8443. No internet port forwarding.
2. Install MandalaGatewaySetup-1.1.0.exe. Open "Mandala office setup" from Start and choose "Internet-connected gateway computer".
3. Select its LAN IP and employee subnet, confirm isolation, then click "1. Create certificates and start gateway". No existing certificates or separate Node installation are needed. The gateway runs automatically in the background, including after restart.
4. Click "2. Export employee setup ZIP" and select MandalaAgentSetup-1.0.15.exe from Downloads. Copy the exported ZIP to the employee PC using the office-approved transfer method.

IT + EMPLOYEE — LAN-ONLY PC
5. Sign into the employee's normal Windows account. Extract the ZIP and open "Employee pairing.cmd". Stop any timer and close Mandala Agent first. Click "1. Install agent and create PC request". IT approves installation when Windows asks. Save the request JSON.
6. Take that JSON to the gateway. In Mandala office setup choose "3. Approve an employee PC request". Confirm the correct PC, save the connection JSON, and note the pairing code shown on that gateway screen.
7. Back in the SAME employee Windows account, enter that pairing code and choose "2. Complete connection". Select the connection JSON and let IT approve the settings. Wait for "Connection verified". The agent opens automatically.

INTERN — TWO-MINUTE FIRST TEST
8. Keep the employee PC on LAN with internet blocked. Sign in to Mandala, select a project, start work and type in a local document for two minutes, then stop. Note the "time saved successfully" reference.
9. Ask the local Mandala administrator to confirm the same reference appears once for the correct employee/project in the web app. A sign-in or loaded project list alone is not a pass. Then use the downloadable quick test checklist for switch/reconnect/idle checks.

IF SOMETHING FAILS
- Missing "LAN https://..." on agent sign-in: close the agent and repeat Complete connection under the same employee Windows account.
- Gateway connection check fails: IT checks the gateway task in Windows Task Scheduler (Mandala LAN Gateway), reserved LAN IP, correct subnet and the Domain/Private Windows network profile. The gateway must have working internet. Do not disable firewall or certificate checks.
- Missing saved reference: preserve the Windows profile/app data and export "Save / copy diagnostics for IT" before repeating. Report the employee, project, PC, IST date/time and screenshot. Do not clear a pending session.
- An existing manual gateway configuration is deliberately preserved. Do not overwrite it or remove certificate settings while employees have pending time.

IT MAINTENANCE
Certificates expire after one year. Schedule certificate maintenance before then; this release does not include automatic renewal. Keep the gateway patched and monitor the background task. Approving another PC briefly restarts the gateway. Only public certificate files move between PCs; the employee private key stays non-exportable in that employee Windows profile. The temporary issuer private keys are never saved.
This installer configures time tracking only. File preview services have separate setup and isolation requirements.
