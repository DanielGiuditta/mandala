# Glossary

## Project
A client-facing architecture job tracked through project stage labels.

## Person
A person tracked in the system.

## Assignment
A staffing record linking one person to one project.

## Time Entry
A recorded span of time for a person working on a project.

## Resource
A document or library asset attached to a project or stored in the shared library.

## Library
A shared repository of non-project reference materials.

## Project Stage
A named lifecycle label for a project in V1.

## Approval
A future workflow concept that may gate stage progression if advanced workflow logic is added later.
