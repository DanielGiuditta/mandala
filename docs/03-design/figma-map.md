## App Shell Notes

- The sidebar and shell chrome live in `apps/web/app/components/app-sidebar.tsx` and `apps/web/app/sidebar-nav.tsx`.
- Keep the Figma layout direction, but bind all shell content to real app state.
- Brand copy must remain `kolam`.
- User identity, office, role, and session status must come from auth/session data.
- Do not hardcode user names, pinned items, or remote Figma asset URLs into the shipping app shell.
- Entity areas that visually behave like workspace overlays should keep the shell stable and use route-backed modal/detail slots inside the domain surface instead of collapsing the global shell on detail routes.
