# packages/domain

Canonical TypeScript domain types for the architecture firm tracker.

The product model is defined in:

- `docs/01-product/prd.md`
- `docs/01-product/domain-model.md`
- `docs/01-product/field-definitions.md`

Current core entities:

- Office
- Person
- Project
- Assignment
- TimeEntry
- ResourceDocument

Project stage labels are modeled on `Project.stage`.
